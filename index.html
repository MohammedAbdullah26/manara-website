Manara منارة

A Wi-Fi security scanner for Android that checks a network before you trust it.

Manara flags fake copies and risky hotspots before you join them, checks the network you're connected to, and helps you find a router with an on-screen radar. Everything runs on your phone.

On a computer? Open this page on your Android phone to install it.

How to install

  1. Tap Download for Android and wait for the file to finish downloading.
  2. Open Manara.apk from the download notification, or from the Downloads folder in your Files app.
  3. If Android says your browser can't install apps, tap Settings, turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect warns about an unknown app, tap More details, then Install anyway.
  5. Open Manara and allow Precise location. Android only gives Wi-Fi scan results to apps that have it.

Good to know

Not from the Play Store

This is a test build of a student project, shared as an APK. That's why Android asks before installing it.

"App not installed"?

An older copy of Manara built on another computer is in the way. Uninstall it, then install this one.

Your data stays on the phone

Scans, scores and the AI model run on the phone. Online reports and cloud backup are off until you sign in and turn them on.
